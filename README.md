# AI-Based Carbon Emission Prediction for Climate Action 🌍

This project is developed as part of the **1M1B AI for Sustainability Virtual Internship**.
It focuses on predicting future carbon emission levels using Machine Learning to support global efforts towards climate action and environmental sustainability.

## 🎯 Objective
The main objective of this project is to analyze historical carbon emission data and build a predictive model that can forecast future CO₂ emission trends. This helps governments, industries, and researchers take early actions to reduce environmental impact.

## 🧠 AI & ML Approach
The project uses a regression-based Machine Learning model trained on historical emission data.  
It identifies trends and patterns in carbon emissions over time and generates future predictions based on learned relationships.

## 🛠️ Technologies Used
- Python  
- Pandas  
- NumPy  
- Scikit-learn  
- Matplotlib  
- Machine Learning (Regression)

## 📂 Project Structure
- `carbon_emission.csv` – Dataset containing year-wise CO₂ emissions  
- `carbon_prediction.py` – Python script for training and predicting emissions  
- `dataset.png` – Dataset screenshot  
- `code.png` – Code screenshot  
- `graph.png` – Emission trend graph  
- `output.png` – Prediction output screenshot  

## 📈 Output
The model predicts future CO₂ emission levels and visualizes emission trends using graphs, helping in better understanding climate impact.

## 🌱 Impact
This project demonstrates how Artificial Intelligence can be used to address real-world environmental problems and supports SDG 13: Climate Action by promoting data-driven sustainability decisions.
